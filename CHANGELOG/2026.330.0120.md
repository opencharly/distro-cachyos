# 2026.330.0120 — fix(check): the GPU-residency check loads a model with a keep-alive first

## Summary

`check-cachyos-ollama-pod`'s `ollama-gpu-resident` check ran a bare `ollama ps`, which lists only
LOADED models — and at that point none was loaded. It red on a CLEAN image in two consecutive runs
while `ollama-gpu-inference` PASSED, so the check's subject (the CUDA backend executed the generation)
was already proven; the red was the check's own timing.

The check now loads a declared model with `keep_alive: 10m` through the API (`curl -fsS`, so a failed
load fails loudly), then asserts the processor column.
