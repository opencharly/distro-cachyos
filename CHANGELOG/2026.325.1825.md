# 2026.325.1825 — feat(cachyos): add the whisper box and move its two beds off Fedora

## Summary

Adds the CachyOS **whisper** box and moves the family's two whisper beds onto it, so the last
service in the local AI stack no longer depends on a Fedora image (opencharly/distro-cachyos#223).

- `box/whisper/charly.yml` — `base: cachyos`, candy `layer-whisper:v2026.325.1751`, the release
  whose `HOME: /home/user` pin makes a **bound** deployment use the mounted model store
  (opencharly/layer-whisper#14, merged as that tag).
- `charly.yml` — `check-whisper-pod` and `check-whisper-auth`, carried over from opencharly/distro-fedora
  with their assertions unchanged. The pod binds the shared model store at `~/.cache/whisper`, so the
  checkpoint is fetched once and reused by every deployment and bed.
- The Fedora box and those two beds are deleted in the companion PR in opencharly/distro-fedora, in
  the same cutover, so exactly one `whisper` box exists afterwards.

No candy change: `layer-whisper` is pixi + `layer-python` + `layer-ffmpeg` and builds on CachyOS
unchanged — whisper runs on CPU, so nothing about the GPU contract is involved.
