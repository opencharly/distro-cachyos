# 2026.325.1412 — fix(pins): advance the arch and podcdi imports to the carrier-fixed generation

## Summary

Advances this repo's two import pins to the generation carrying today's owned-skill carrier
chain, so the CachyOS boxes it builds — and every repo importing it — stop failing a cold build
(opencharly/distro-cachyos#220).

```diff
-    - arch:    '@github.com/opencharly/distro-arch:v2026.324.0908'
-    - podcdi:  '@github.com/opencharly/pod-cdi:v2026.324.1644'
+    - arch:    '@github.com/opencharly/distro-arch:v2026.325.1112'
+    - podcdi:  '@github.com/opencharly/pod-cdi:v2026.325.1329'
```

**The defect, measured in a consumer.** opencharly/layer-openclaw's `check-openclaw-pod` builds its
gateway on the CachyOS base this repo hands it, and failed there:

```
charly: error: command "build": building cachyos.arch.arch: …
#10 [stage-1 6/7] COPY --from=arch-skills … .agents/skills /home/user/.agents/skills
#10 ERROR: failed to calculate checksum of ref …: "/.agents/skills": not found
```

That is the pre-#76 shape. A consumer cannot fix it from its own `arch:` import — the base it
inherits from `cachyos` is built here, from this repo's pins. Three things were blocked behind it:
opencharly/layer-openclaw#14 (its bed), the umbrella's ability to load (its `layer-openclaw` import
resolves through this repo), and the whisper box this repo is adding.

`podcdi` moves too because the CDI pod base has the same requirement at its own layer
(opencharly/pod-cdi#10, merged as `v2026.325.1329`).
