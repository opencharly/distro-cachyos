# 2026.265.1729 — feat(cachyos): own the cachyos family skills in distro-cachyos

## Summary

Move the 12 CachyOS-family `skill:` entities out of the `layer-charly-*` concept
aggregators into this repo — the repo that owns the artifacts they document.
Each entity is copied verbatim, with `owner:` corrected to the skill's own name
(the convention every single-candy repo uses).

The entities are placed in THREE `candy/<dir>/charly.yml` files
(`candy/cachyos-os-skills`, `candy/cachyos-selkies-skills`,
`candy/cachyos-app-skills`) rather than one 2033-line block in the root
`charly.yml`. `candywalk` discovers `candy/<dir>/charly.yml` identically to a
root node (already proven in `distro-arch`, which owns `candy/arch-pac-test`
this way), AND the per-file diff then stays under the org reviewer's 64 KB
per-file result cap — the combined root-manifest diff (127 KB) exceeded that cap,
so the earlier PR (#90, now closed) was handed an EMPTY diff and could not be
reviewed. The split makes every file reviewable.
