asserts exactly the set the box ships.

  tag match (`grep -qxF`). RED on an image whose service still execs `ollama serve`, RED for a
  mistyped or removed tag.

## Round-3 review fixes

- **Block 1 — the pull check's failures now have valid RCAs from their own runs**, and the design
  changed so it cannot fail for those reasons again:
  - `2026.328.0220`: a SECOND scratch wrapper on another port never answered → the check sat out
    its deadline. Removed.
  - `2026.328.0315`: direct `ollama pull`s were **killed while racing the wrapper's own concurrent
    pull** of the same 6 GB. Removed.
  - `2026.328.0152`: that run raised the bed's GPU gate to 2 GiB on a contended card, so the
    wrapper refused to start the server and the start-time pull never ran — an artefact of MY gate
    experiment, reverted.
  The check is now an ASSERTION over the wrapper's own pull (bounded wait, exact match), which
  passes in three runs.
  **Missed control (R1):** all three designs reached the branch because my pre-push gate had no
  control for a CHECK's OWN failure paths — I verified the changed box content and then ran the
  bed, but never executed the new check's command against a live target BEFORE committing a
  design, and each failure mode (a second server that never answers; a pull racing the wrapper's
  own; a gate that blocks the start) is invisible until the check actually runs. The control now:
  a new check is exercised once against the live target before it is committed, and the body names
  what that run proved.
- **Block 2 — the four models' residency is no longer claimed as measured.** The box comment now
  states the measured free window and the per-model q4 sizes as a **sizing estimate**, and names
  the one model measured at 100% GPU (`qwen3-vl:2b-instruct-q4_K_M`, 1.9 GiB / 1.9 GiB in the
  operator pod). The bed's residency step still exercises `qwen2.5:0.5b`; per-model residency for
  all four is FILED as opencharly/distro-cachyos#245 (listed below).
- **Non-blocking notes taken:** exact tag match (`grep -qxF "$m"`); the validate invocation and its
  output are pasted above; the poll margin is gone with the direct-pull design (the remaining wait
  is 900×2 s inside a 40 m step timeout).
