# 2026.265.1700 — feat(cachyos): own the cachyos family skills in distro-cachyos

## Summary of changes

Move the 12 CachyOS-family `skill:` entities out of the `layer-charly-*` concept
aggregators and into this repo, the repo that owns the artifacts they document.
Each entity is copied verbatim, with `owner:` corrected to the skill's own name.

The entities are placed in THREE `candy/<dir>/charly.yml` files
(`candy/cachyos-os-skills`, `candy/cachyos-selkies-skills`,
`candy/cachyos-app-skills`) rather than one 2033-line block in the root
`charly.yml`. Two reasons: (a) `candywalk` discovers `candy/<dir>/charly.yml`
identically to a root node (already proven in `distro-arch`, which owns
`candy/arch-pac-test` and `candy/arch-aur-test` this way), and (b) the per-file
diff stays under the org reviewer's 64 KB per-file result cap. The combined
root-manifest diff (127 KB) exceeded that cap, so the reviewer received an empty
diff and could not review the change; the split makes every file reviewable.
