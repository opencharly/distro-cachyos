# 2026.320.1625 — feat(cachyos)!: re-home clawsweeper-review from distro-ubuntu to a CachyOS pod

## Summary

Re-homes the ClawSweeper review image from `distro-ubuntu` to **a CachyOS pod** — operator decision
**D-3** of opencharly/opencharly#1068: the org's non-CachyOS images retire, so the review tool moves
rather than disappearing with the Ubuntu base it happened to live on.

Two additions (head `d2cc37a`, two commits — the second removes a port artifact and adds no content):

- `box/clawsweeper-review` — the image, `base: cachyos`, one candy ref.
- `check-clawsweeper-review-pod` — the disposable bed, **ported from `distro-ubuntu`'s bed with its
  plan intact**: a self-built git fixture carrying a deliberate defect, the entrypoint's flag
  contract, `jq` present, the engine reaching the model boundary, and nothing failing on the image's
  own permissions.

**Producer first — this could not be built until the candy could.** The candy declared **only** an
`ubuntu:` `distro:` section, so an image composed on CachyOS installed *no dependencies at all* and died
at the Node step. That was fixed and **merged first**: opencharly/layer-clawsweeper#11 → tag
**`v2026.320.1554`** (the Arch package set, plus a `libicu78` fix for Ubuntu 26.04). The pin here is
that tag, and the comment in the box says why it is the first tag that can work at all.
