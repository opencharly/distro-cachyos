# 2026.242.0622 — fix(beds): use the map form for the punktfunk verb in check-punktfunk-pod

## Summary
The check-punktfunk-pod bed used the scalar shorthand for the `punktfunk:` check verb (`punktfunk: health`), but the host's project parse (sdk/loaderkit/parse.go) only accepts scalar shorthand when the plugin's Describe response declares a primary field — and the plugin is not connected at parse time, so the parse failed with "plugin verb \"punktfunk\" takes a MAP input (it declares no primary field for the scalar shorthand)". This blocked the image-build step of every bed whose project closure includes box/cachyos (check-agentteams-snapshot, check-boxload-pod, check-sidecar-pod).

Fix: convert the four scalar-shorthand steps to the explicit map form (`punktfunk: {method: health}` etc.), which the parse accepts without needing the plugin connected. The json_path step already used the map form.
