# 2026.324.2235 — feat(cachyos): pin the merged AI-stack releases and share one host model store

## Summary

Consumes the merged producer releases for the local AI stack, shares one host model store
across the deployments and the beds, and makes every bound model pod — and the Open Web UI
0.13.4 image-generation path — actually use its mounted/configured backend.

- **Producer pins (CalVer tags only):** `pod-openwebui v2026.324.1208` (Open Web UI 0.13.4),
  `plugin-openwebui v2026.324.1215`, `pod-comfyui v2026.324.1925` (ComfyUI v0.46.1 + the bound
  `HOME` fix), `pod-qwen3-tts v2026.324.1852` (fork consumer + `HOME`/`HF_HOME` bound fix).
- **One host model store:** artifacts under `$XDG_DATA_HOME/charly/models/<server>` (ComfyUI,
  Hugging Face, Ollama, Whisper); per-deploy state under `volumes/<deploy>/<volume>`. The beds
  bind only the shared model subdirectory and keep their state volume fresh, so the ~12 GB
  Z-Image set and the Qwen checkpoint are fetched once, not per run.
- **Bound pods use their volumes:** a host-owned bind runs the container as root under keep-id
  (`HOME=/root`), so the qwen/comfyui candies pin `HOME` (and `HF_HOME`). The comfyui bed's
  `comfyui-home-pinned` control asserts `HOME==/home/user` and the checkpoint in the bound tree.
- **The pair bed's 0.13.4 image path (fixed in-tree):**
  - `ENABLE_API_KEYS: "true"` — 0.13.4 gates `POST /api/v1/auths/api_key` behind it;
  - `ENABLE_PERSISTENT_CONFIG: "true"` — 0.13.4 migrates the legacy env into a **connection**
    once; without persistence the migrated connection is invisible and generation fails;
  - the checkpoint is written into the connection's **workflow** (and the dynamic nodes kept):
    0.13.4's `_workflow_nodes` drops a static node's `value`, so a `ckpt_name` node cannot set
    the checkpoint — tracked as opencharly/pod-openwebui#28, with this workflow-based workaround.
- **Bed assertions:** openwebui `0.13.4`; comfyui `0.46.1` at `/system_stats` and
  `/opt/comfyui/.charly-ref`; `check-comfyui-pod` claims the shared GPU and asserts the served
  release; qwen proves the idle unload/reload state machine.
