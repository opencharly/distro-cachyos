# Schema compaction — compact node grammar + SSH port auto-allocation

`charly migrate` (compact-node-form, schema 2026.186.2323) reshaped every
charly.yml to the compact grammar (inline collections, ordered `plan:` lists,
`<word>: <input>` verb sugar, live-verb fields folded into their input maps,
`env:` maps). Full `charly box validate` green against the new loader.

Every VM bed (check-cachyos-vm / check-cachyos-gpu-vm / check-selkies-*-nvidia-vm)
now AUTO-ALLOCATES its SSH host port (`ssh: {port_auto: true}`) instead of a
hardcoded `1222x` port — the fix for a real host-port collision under a parallel
roster (two beds had both pinned SSH `12227`).
